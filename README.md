## 这是什么

**从"中医"技能提炼的专科分支**,两层知识结构:

- **通用基础层(已内置本技能 `references/通用中医/`)**:中医基础/诊断/中药/方剂/针灸/安全的方法与纪律——已将六部教材与 42 部原典的逐字整理**完整复制进本库**(`references/通用中医/` 全套 references 与 `sources/` 经典原文),不再依赖外部"中医"技能,可离线独立运行。
- **眼科专科层(本 Skill 新增)**:五轮八廓学说、眼与脏腑经络关系、眼科病因病机与诊法、五轮/内障外障辨证、约 47 种中医眼科病种分证论治(含 7 个古籍增补病种)、眼科专属中药(约 76 味,按明目退翳分组)、眼科方剂(约 90 首,含三书古籍原书方论)、眼科针灸与外治(穴位定位主治、病证配穴、眼保健操、非药物安全分级、审视瑶函针灸要穴歌括)、经典条文层(《黄帝内经》目论 + 三书方证条文 + 原机启微病机十八条式辨证框架 + 审视瑶函金玉赋/内外二障论)。

核心设计:

- **SKILL.md 只放工作流程与索引**(问题分流、眼科七步骤、涉药四关、选方路径、红线),事实细节全部在 `references/`(10 个文件:00~08 + 安全表)按需加载(渐进披露)。
- **五轮定位 → 辨证 → 立法 → 选药 → 选方 → 按穴/眼保健操 → 经典溯源链条完整**:从眼部主症定五轮、由证型立治法、按治法给候选药群与成方比选,同一辨证下药物(B 级)与按穴/眼保健操(A 级)两条干预线并行,全程有出处。
- **安全红线是硬约束**:青光眼禁用一切扩瞳药(青葙子/洋金花)、点眼药严禁自制、眼区危险穴禁按压禁灸、有创外治绝对禁自行;凡涉具体药物与成方必先过 `安全-眼科用药与外治安全` 与 `通用中医/安全-配伍妊娠禁忌与毒性药.md`(通用安全总表,已内置本库)。
- **定位是"参谋"而非"医师"**:如实声明 AI 身份,不扮演执业医师;所有建议按 A(起居/忌口/药食两用食疗/热敷熏洗/眼保健操/安全穴按穴)、B(须医师把关:一切内服药、成方、点眼药)、C(立即眼科急诊:视力骤降/绿风发作/穿通伤/化学伤/疳积上目等)分级明示。

## 能做什么

- 讲解眼科中医理论(五轮八廓、肝开窍于目、眼与脏腑经络、久视伤血)并注出处
- 解读眼部症状(目赤肿痛、视物昏花、目痒流泪、眼干涩、眼前黑影、视力下降、瞳神变化)含义与五轮归属;按五轮/内障外障/脏腑气血津液辨证,走"证候诊断七步骤"输出证型+病机+治法方向
- **病种直达**:针眼、睑弦赤烂、暴风客热、天行赤眼、聚星障、凝脂翳、瞳神紧小、绿风内障、青风内障、圆翳内障、云雾移睛、视瞻有色、视瞻昏渺、青盲、高风内障、暴盲、撞击伤目、异物入目、能近怯远、疳积上目、消渴目病,及古籍增补的胬肉攀睛、蟹睛、黄膜上冲、妇人倒经、小儿痘疹入眼、神水将枯、鹘眼凝睛等约 47 病种——定义、五轮归属、鉴别(含与致盲病鉴别)、分证论治表(含古籍增补方)、**红线指征**、调护
- 查询约 76 味眼科中药的性味归经、明目退翳功效、用法用量与警示(含扩瞳/青光眼禁忌、三书退翳点眼药性);按病证反查候选药群
- 查询约 90 首眼科方剂(杞菊地黄丸、明目地黄丸、石斛夜光丸、驻景丸、龙胆泻肝汤、石决明散、除风益损汤等)的组成用量、功用主治、方义、加减与类方鉴别;**三书古籍原书方论**(原机启微附方君臣佐使全解、审视瑶函重点方、银海精微代表方)
- **眼科穴位与家庭外治**:查眼科穴位定位主治(教定位法)、眼病病证配穴、转为**按穴按摩(A 级)与眼保健操(A 级)**;灸法/耳穴压豆(A⁻ 级,连同禁忌);**针刺等有创外治只解释原理与风险,绝不指导自行操作**
- **处方解读与安全复核**:把医师开的眼科方逐药讲明,并做配伍/人群(尤其青光眼)/剂量三重核对——只解读、只核对,不评判
- **就医沟通单**:就诊前把主诉、病程、眼科十问、舌象、既往用药(尤降糖降压降眼压药)整理成医师可直接使用的陈述
- **经典溯源**:《黄帝内经》目论(五脏六腑精气上注、肝开窍于目、心使目、目得血而能视、久视伤血、五轮雏形、目系连脑)原文与篇名出处;**三书条文溯源**——《银海精微》审瞳法/药性论/用药次第、《原机启微》病机十八条与君臣佐使方论、《审视瑶函》五轮八廓歌括/目为至宝论/内外二障论/金玉赋/金针拨内障十六般/针灸要穴歌括
- **现代眼科共识筛查与转诊**(v1.3):解读高度近视分级(SE≤−6.00 D、病理性近视、黄斑分级 0~4)、眼轴长度与轴率比阈值(≥6 岁 AL/CR>2.90 须睫状肌麻痹验光、6~10 岁年增长 <0.20 mm 为安全界)、AI 眼底黄斑 13 类体征与低/中/高分级转诊;凡触红线一律指西医眼科,**不作诊断、不开处方**(详见 `09-现代眼科共识与筛查要点`)
- **非致命眼症应急支持**:麦粒肿初起、轻症红眼、眼疲劳干涩等排不上正规医疗时,给"等待期支持"——先排红线、再给基础护理+中医 A 级措施、必附升级指征与就医时限

## 不能做什么(边界)

- **不是诊断工具,不开处方**:输出止于"证型+治法方向+候选药群/成方比选",具体用药必须由执业中医师/中医眼科医师面诊确定
- **眼科红色急症一律指向立即眼科急诊**(视力骤降、绿风发作、穿通伤、化学伤、异物嵌顿、小儿瞳神发白夜盲),不提供家庭替代;非致命急症应急仅限"等待就医期间"
- **点眼药严禁自制**(炉甘石/硼砂/冰片类只建议正规制剂);**青光眼禁用一切扩瞳倾向药**;**眼区危险穴(睛明/承泣/球后)家庭不按压不灸**;针刺/针拨内障等有创外治绝对禁自行
- **明确不含**:尚未取得文本的《眼科龙木论》《目经大成》《一草亭目科全书》逐条方论(存目待补,见 `sources/_目录与状态.md`);《银海精微》《原机启微》《审视瑶函》三书 v1.2 已通读落盘,其方证条文与原书方论见 `08`/`06`;西医眼科检查判读(只作红线分流与佐证);眼科手术与有创治疗(只解释指路);西药眼科用药药理(只作配伍提醒);中成药品种库(仅收教材同名成方指认);《药典》法定剂量(现有剂量为教材值)
- 现代疾病(糖尿病视网膜病变、高血压眼底)不做"病名→药"直译,先转中医病证再辨证,且不建议自行停用西药(降糖/降压/降眼压)

## 工作机制

1. **分流**:SKILL.md 按问题类型路由——概念解释直答;眼部主诉对上病种先查 `04` 病种节,否则走眼科七步骤;涉药问题过"性能→配伍→人群→剂量炮制"四关;选方先查 `00` 总索引再入 `06` 核对类方鉴别;穴位/外治走 `07` 并过非药物分级;经典目论走 `08`。
2. **互链**:`05` 中药↔`06` 方剂双向指引;`04` 病种分证表回指 `06`/`05`;`07` 穴位与 `04` 病种红线互指;`08` 经典与 `01`/`03` 互链;全库以 `[[安全-眼科用药与外治安全]]` 挂钩安全表。
3. **引用规范**:引用《黄帝内经》注篇名出处、区分教材转述与原文;剂量一律注明"教材参考值,未经《药典》校准";古方原量不作用药依据。

## 数据源与质量说明

- 本 Skill 的通用中医理论/诊断/中药/方剂/针灸/安全内容,来源于本地"中医"技能的方法学与知识结构,**已完整复制进本技能专属目录**:全套通用 references 位于 `references/通用中医/`(`00`~`48` + 通用安全总表),经典原文 `黄帝内经素问.txt`/`黄帝内经灵枢.txt` 位于 `sources/`。本技能不再依赖外部"中医"技能即可独立运行。

- 通用中医的条目级机械自查纪律继承自内置的 `references/通用中医/` 参考库;本库眼科新增条目以"查表而非凭记忆"为铁律,未收录内容一律明示并指路。
